1 Quick Start

Install MetaForge and get the server running in two commands.

Prerequisites

Python 3.9+ and pip. An OpenAI API key is required for AI-powered features (screening, extraction, quality assessment).

Install via pip

# Install MetaForge from PyPI
pip install metaforge

# Or install from source for the latest features
git clone https://github.com/MetaForge/metaforge.git
cd metaforge
pip install -e .

Configure Environment

# Set your OpenAI API key (required for AI modules)
export OPENAI_API_KEY="sk-your-key-here"

# Optional: set a custom port (default is 8501)
export METAFORGE_PORT="8501"

Launch the Server

# Start MetaForge server
metaforge serve

# Or run with Streamlit directly
streamlit run metaforge/app.py --server.port 8501

# Server will be available at http://localhost:8501
Tip: For production deployments, use metaforge serve --host 0.0.0.0 --port 80 and place behind a reverse proxy.

3 Running Your First Analysis

Execute a complete meta-analysis programmatically or via the Workbench.

Python API — Quick Analysis

from metaforge import MetaAnalysis
from metaforge.stats import RandomEffects, FixedEffects

# Initialize with your data
ma = MetaAnalysis(
    data="path/to/studies.csv",
    method="random",          # "fixed", "random", or "peto"
    model="DL",               # DerSimonian-Laird estimator
    measure="OR"              # OR, RR, RD, SMD, HR
)

# Run the analysis
results = ma.run()

# Print summary
print(results.summary())
# ┌─────────────────────────────────────────────────┐
# │  Pooled OR: 1.42 (95% CI: 1.18–1.71)           │
# │  Heterogeneity: I²=34.2%, τ²=0.04, p=0.003     │
# │  Test for overall effect: Z=3.68, p=0.0002      │
# └─────────────────────────────────────────────────┘

# Generate forest plot
ma.plot_forest(output="forest_plot.png", dpi=300)

# Generate funnel plot for publication bias
ma.plot_funnel(output="funnel_plot.png")

# Subgroup analysis
subgroup = ma.subgroup(by="region")
print(subgroup.summary())

Using the Workbench (Visual Mode)

In the Workbench, click "Run Analysis" after configuring your data. The AI will:

  1. Auto-select the appropriate statistical model based on your data characteristics
  2. Run heterogeneity tests (Cochran's Q, I², τ²)
  3. Generate forest plots, funnel plots, and Galbraith plots
  4. Perform sensitivity analysis (leave-one-out)
  5. Assess publication bias (Egger's test, Begg's test, trim-and-fill)
  6. Generate a PRISMA-compliant report

4 Understanding Results

Learn to interpret the key outputs of your meta-analysis.

Forest Plot Interpretation

ElementMeaning
SquaresIndividual study effect sizes. Larger squares = larger study weight.
Horizontal lines95% confidence interval for each study.
DiamondPooled effect estimate. Width = 95% CI of the pooled estimate.
Favors left/rightDirection of effect. Line of no-effect (OR=1, SMD=0) shown as dashed vertical.
Prediction intervalDashed diamond showing the range of true effects in future studies.

Heterogeneity Metrics

MetricInterpretation
I² < 25%Low heterogeneity — studies are consistent.
I² 25–75%Moderate heterogeneity — explore with subgroup or meta-regression.
I² > 75%High heterogeneity — investigate sources; consider if pooling is appropriate.
Cochran's QChi-squared test. p < 0.10 suggests significant heterogeneity.
τ² (tau-squared)Between-study variance. Higher values = more variability in true effects.
Tip: I² alone can be misleading with few studies. Always report Q, τ², and prediction intervals alongside I².

Publication Bias Assessment

MetaForge automatically runs multiple tests:

TestWhen to Use
Egger's regressionContinuous outcomes with ≥10 studies.
Begg's rank testNon-parametric alternative; robust with smaller samples.
Trim-and-fillEstimates number of missing studies and adjusts the pooled effect.
Funnel plotVisual inspection for asymmetry (subjective but essential).

5 Exporting Reports

Export your results in multiple formats for publication, collaboration, or further analysis.

CSV Export

# Export study-level data and pooled results
results.export_csv("my_meta_analysis.csv")

# Output columns: study, TE, seTE, lower, upper, weight, z, p

JSON Export

# Full structured output for programmatic use
results.export_json("results.json", pretty=True)

# Includes: pooled_effect, ci_lower, ci_upper, heterogeneity,
# publication_bias_tests, study_details, subgroup_results

PDF / LaTeX Report

# Generate a PRISMA-compliant PDF report
results.export_report(
    format="pdf",
    template="prisma",        # "prisma", "cochrane", "jama"
    include_plots=True,
    language="en"             # "en" or "zh"
)

# Export LaTeX source for journal submission
results.export_report(format="latex", output="report.tex")
Tip: PDF reports include forest plots, funnel plots, PRISMA flow diagram, risk of bias summary, and all statistical tables — ready for supplementary material submission.

6 API Usage

Use the REST API to integrate MetaForge into your automated pipelines.

Start a Search

curl -X POST http://localhost:8501/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SGLT2 inhibitors heart failure",
    "databases": ["pubmed", "cochrane"],
    "date_range": ["2015-01-01", "2025-12-31"],
    "study_types": ["RCT"]
  }'

Screen Studies

curl -X POST http://localhost:8501/api/screen \
  -H "Content-Type: application/json" \
  -d '{
    "search_id": "srch_abc123",
    "criteria": {
      "include": ["adults", "heart failure", "SGLT2i", "RCT"],
      "exclude": ["pediatric", "observational", "case report"]
    },
    "model": "gpt-4o"
  }'

Run Statistical Analysis

curl -X POST http://localhost:8501/api/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "proj_xyz789",
    "method": "random",
    "model": "DL",
    "measure": "HR",
    "subgroup_variable": "region",
    "sensitivity": true,
    "publication_bias": ["egger", "begg", "trim_fill"]
  }'

Generate Plots

curl -X GET http://localhost:8501/api/plots/proj_xyz789/forest \
  -H "Accept: image/png" -o forest.png

curl -X GET http://localhost:8501/api/plots/proj_xyz789/funnel \
  -H "Accept: image/svg+xml" -o funnel.svg

Export Results

# Export as JSON
curl -X GET http://localhost:8501/api/export/proj_xyz789?format=json \
  -o results.json

# Export as PDF report
curl -X GET http://localhost:8501/api/export/proj_xyz789?format=pdf \
  -o report.pdf
Full API reference: See api.html for complete endpoint documentation, authentication, rate limits, and response schemas.

⚡ Troubleshooting

Common Issues

ProblemSolution
ModuleNotFoundError: metaforgeEnsure you're in the correct virtualenv. Run pip install metaforge again.
OPENAI_API_KEY not setExport the key: export OPENAI_API_KEY="sk-..."
Port 8501 already in useKill the existing process or use a different port: metaforge serve --port 8502
Forest plot not renderingInstall matplotlib backend: pip install matplotlib and ensure a display server is available (or use Agg backend for headless).
Search returns 0 resultsCheck your PICO terms. Try broader keywords. Verify database connectivity with metaforge test-db.
Analysis hangs at screeningReduce concurrent threads: metaforge serve --threads 4. Check your OpenAI API rate limits.
MemoryError with large datasetsIncrease system memory or use chunked processing: ma.run(chunk_size=100).
Need more help? Open an issue on GitHub or email support@metaforge.com.
