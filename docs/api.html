API Documentation

30+ REST endpoints for programmatic meta-analysis. Base URL: /api

Core Analysis
GET /api/health Health check

Returns server status, version, and timestamp.

POST /api/analyze Run complete meta-analysis

Execute a full meta-analysis with forest plot, funnel plot, subgroup, and sensitivity analyses.

ParameterTypeDescription
studiesarrayList of study objects: name, e_events, e_total, c_events, c_total, subgroup, data_type
modelstring"fixed" or "random" (default: "random")
effect_measurestring"OR", "RR", "SMD" (default: "OR")
{ "studies": [ {"name": "Study 1", "e_events": 30, "e_total": 100, "c_events": 20, "c_total": 100}, {"name": "Study 2", "e_events": 45, "e_total": 120, "c_events": 35, "c_total": 110} ], "model": "random", "effect_measure": "OR" }
POST /api/demo Run demo analysis

Run a complete meta-analysis with built-in NSCLC PD-1 demo dataset (10 studies). No parameters needed.

Visualization
POST /api/forest Generate forest plot SVG

Generate a publication-quality forest plot. Parameters: studies (array), effect_measure (string).

POST /api/funnel Generate funnel plot SVG

Generate a funnel plot for publication bias assessment.

POST /api/galbraith Generate Galbraith (radial) plot

Galbraith plot showing z-statistics vs precision. Useful for visualizing heterogeneity.

POST /api/labbe Generate L'Abbe plot

L'Abbe plot showing event rates in treatment vs control groups. Useful for visual assessment of treatment effects.

POST /api/prisma Generate PRISMA 2020 flow diagram

Generate a PRISMA 2020 compliant flow diagram. Parameters: total_found, after_dedup, after_screen, included.

Bias & Sensitivity
POST /api/bias Publication bias tests

Run Egger's regression test, Begg's rank correlation test, and Trim-and-fill analysis. Requires at least 3 studies.

POST /api/cumulative Cumulative meta-analysis

Progressive meta-analysis adding studies one at a time. Shows how the pooled estimate evolves.

Advanced Statistics
POST /api/meta_regression Meta-regression analysis

Regress effect sizes on a covariate (e.g., sample size, publication year, drug dose). Parameters: studies, covariate (array of floats), covariate_name.

POST /api/dose_response Dose-response meta-analysis

Fit linear and restricted cubic spline models of effect vs dose. Parameters: studies, doses (array of floats), num_points.

Network Meta-Analysis
POST /api/nma/analyze Full NMA analysis

Run Network Meta-Analysis. Computes direct, indirect, and network estimates, consistency assessment, SUCRA ranking, and generates network diagram and league table SVGs.

ParameterTypeDescription
comparisonsarrayList of comparisons: treatment_a, treatment_b, effect, ci_lower, ci_upper
GET /api/nma/demo NMA demo with oncology data

Run NMA with 5 immunotherapy treatments vs chemotherapy vs best supportive care. No parameters needed.

POST /api/nma/network NMA network diagram

Generate an SVG network diagram showing treatment nodes and comparison edges.

POST /api/nma/league NMA league table

Generate an SVG league table showing all pairwise treatment comparisons with effect sizes and confidence intervals.

Export
POST /api/export/csv Export results as CSV

Download meta-analysis results as a CSV file with all study-level and pooled estimates.

POST /api/export/json Export results as JSON

Download meta-analysis results as a structured JSON file.

POST /api/upload/csv Upload CSV and analyze

Upload a CSV file with study data and run meta-analysis. Expected columns: name, e_events, e_total, c_events, c_total, subgroup.

POST /api/report/pdf Generate printable HTML report

Generate a complete meta-analysis report as printable HTML with all figures, tables, and statistical summaries.

AI Agents
POST /api/ai/search AI literature search

Simulated AI-powered literature search across academic databases. Returns structured results with PMIDs, titles, abstracts.

POST /api/ai/screen AI screening

Simulated AI-powered PICOS-based literature screening with inclusion/exclusion decisions.

POST /api/ai/extract AI data extraction

Simulated AI-powered data extraction from study PDFs with confidence scores.

User System & Collaboration
POST /api/register Register new user

Create a new user account. Parameters: username, email, password.

POST /api/login User login

Authenticate and receive a session token. Parameters: username, password.

POST /api/projects/save Save project

Save a meta-analysis project (requires authentication). Parameters: name, studies, settings.

GET /api/projects/list List user projects

List all projects for the authenticated user.

POST /api/share Create share link

Generate a shareable link for a project. Returns a share token.

GET /api/shared/{share_token} Access shared project

Access a shared project by its token. No authentication required.
