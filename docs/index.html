Core Capabilities

Everything You Need for Meta-Analysis

From data import to publication-ready reports, powered by statistical rigor and AI automation.

Multi-Format Import

Import data from RevMan, Covidence, R, Stata, and CSV. Automatic column detection and data validation.

Forest & Funnel Plots

Publication-quality forest plots, funnel plots, Galbraith, L'Abbe, and Baujat plots with customizable styling.

Multiple Models

Fixed-effect and random-effects models (DerSimonian-Laird, REML, Paule-Mandel, HKSJ adjustment).

Bias Assessment

Cochrane RoB 2, ROBINS-I, Newcastle-Ottawa Scale. Automated risk-of-bias summary plots.

PRISMA Reports

One-click PRISMA 2020 compliant reports with all figures, tables, and statistical summaries in bilingual format.

Advanced Analytics

Meta-regression, dose-response analysis, cumulative meta-analysis, network meta-analysis, and sensitivity analysis.
